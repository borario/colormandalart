# colormandalart

Color Mandalart is a static web app for creating a themed Mandalart board and exporting it as an image.

## Preview locally

```bash
npm start
```

Then open:

```text
http://127.0.0.1:8765/index.html
```

You can also run the site without npm:

```bash
node work/server.js
```

## Project structure

- `outputs/index.html`: the website
- `outputs/assets/`: icon assets
- `work/server.js`: local preview server
